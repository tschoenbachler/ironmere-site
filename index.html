Glenrock In development

Glenrock is a supervisory building automation and IoT platform that lets systems integrators build and commission sites for the people who own buildings. It connects HVAC controllers, air handlers, meters and sensors to the cloud for real-time visibility, trends, alarms and remote control.

Building control networks such as BACnet and Modbus were designed for closed, isolated networks, with no encryption or authentication. Glenrock links that equipment to the cloud without exposing the building's control network to the internet.

Glenrock is an early-stage reference implementation and is not yet available as a product. If you are an integrator or building owner interested in this direction, we would like to hear from you.

How it fits together

Cloud first, with control kept close to the building. A Glenrock Edge device installed in the building is the secure gateway between the building's control network and the cloud, and critical operations stay local.

What it is designed to do

See everything
Live values, trends and alarms from across a site's buildings and areas, in one place.
Commission quickly
Integrators set up sites, buildings and areas as a draft, apply device templates, and publish when ready.
Serve integrators
Built so integrators can offer monitoring as an ongoing service for recurring revenue.
Share safely
Separate access for administrators, operators and viewers, with each owner's data kept apart.
Stay in control
Alarms and schedules keep working if the internet connection drops.
Secure by design
Hardware-backed device identity, and every service enforces its own access control.
